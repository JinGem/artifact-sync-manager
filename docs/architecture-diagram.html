Architecture · Artifact Sync Manager

版本同步助手 · 三进程架构

Electron 主进程 + Preload 安全桥接 + Vue 3 渲染层：无后端、无数据库，状态持久化在本地 JSON，构建产物直接读写内网共享目录。

No Backend · No DB

无后端 · 无数据库

所有状态持久化在本地 app-state.json（操作者 + 项目列表）；远程目录按 <version> 组织，每个版本根目录存放 .version.json 元数据。

Security Boundary

Preload 安全桥接

  • contextIsolation + nodeIntegration: false
  • 渲染进程只能调用 window.artifactSync
  • 特权操作全部走主进程 IPC

Watch & Push

监控与推送

WatcherService 每 30s 轮询并以 fs.watch 兜底，检测到远程版本变化后同时发系统通知并推送到渲染层。
