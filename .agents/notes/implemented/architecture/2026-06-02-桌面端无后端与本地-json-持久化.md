# Agent Note: 桌面端无后端与本地 JSON 持久化

Status: implemented

## Problem

产品面向公司内网开发者的 Windows 桌面环境，需要保存操作者、最近项目、项目路径和规则。引入独立服务或数据库会增加部署、权限和运维步骤，而单机配置规模很小。

## Decision

应用采用 Electron 桌面端直连本地或共享目录，不引入后端服务、账号系统和数据库。`src/main/config/store.ts` 的 `appStateStore` 将状态读写到 `app.getPath("userData")/config/app-state.json`；状态当前包含 `settings` 和 `projects` 两部分。项目名称按大小写不敏感去重，写入采用整文件 JSON 序列化。

## Alternatives considered

- **独立 Node.js 服务**：需要额外部署、进程守护、端口和鉴权配置，超出当前文件同步需求。
- **SQLite 或 ORM**：查询规模小，数据库文件和迁移机制增加维护成本，也不便于直接排查。
- **每个项目独立配置文件**：多文件一致性更难控制，项目列表更新需要跨文件协调。

## Consequences

配置可以直接查看和备份，安装包不依赖网络服务。应用必须自行处理 JSON 解析失败、目录不可用和写入失败；多个应用实例同时写同一状态文件不受支持，当前通过单实例锁避免并发启动。
