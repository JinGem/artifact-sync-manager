# Agent Note: 远程版本目录与元数据布局

Status: implemented

## Problem

上传产物需要支持历史版本浏览、下载还原和人工排查。版本信息必须能在没有数据库的情况下定位，并且下载时要知道原始源目录名。

## Decision

远程目录直接使用版本号作为一级子目录：`<remoteDirectory>/<version>/<sourceFolderName>/`。上传时 `uploadVersion()` 在版本根写入 `.version.json`，记录 `version`、`operator`、`uploadedAt`、`fileCount`、`sourceFolderName` 和可选 `description`；下载时读取 `sourceFolderName` 将内容还原到本地同名目录。版本扫描只识别 `vX.Y.Z` 目录。

## Alternatives considered

- **所有文件平铺在远程根目录**：不同版本会冲突，无法安全还原目录结构。
- **单一远程索引 JSON**：索引与文件内容可能不同步，多人访问时更新冲突。
- **数据库记录版本**：违反无数据库和可手工检查的约束，增加部署复杂度。

## Consequences

版本目录可以直接在文件管理器中检查、复制或归档。版本元数据写入失败时不会阻断产物文件；没有 `.version.json` 的目录仍可通过当前下载逻辑从版本根读取。
