# Agent Note: GitHub 风格主题令牌系统

Status: implemented

## Problem

界面同时使用 Tailwind CSS 和 Element Plus，需要支持系统浅色/暗色，并保持组件、弹窗、表单和状态色的视觉一致。分散写颜色会使新增页面和第三方组件产生色差。

## Decision

`src/renderer/src/styles/main.css` 定义 `--as-*` 语义变量，使用 `light-dark()` 提供浅色和暗色值，并通过 Tailwind `@theme` 映射为 `bg-page`、`text-fg`、`border-line`、`bg-accent-soft` 等工具类。`src/renderer/src/styles/element/index.scss` 在构建时覆盖 Element Plus 的 SCSS 基础变量，组件级差异集中在 `main.css` 的 `--el-*` 变量区域，不使用 `!important`。

## Alternatives considered

- **组件内写死颜色**：新增组件需要重复选择颜色，暗色容易出现不可见或对比不足。
- **只覆盖 Element Plus 变量**：Tailwind 工具类和页面背景无法共享同一颜色来源。
- **JavaScript 监听系统主题并切换 class**：需要额外状态同步，CSS `light-dark()` 已能表达系统配色。

## Consequences

新增语义色必须同时扩展 `--as-*` 和 Tailwind 映射；组件只使用语义工具类。视觉改动需要检查浅色、暗色、Element Plus 弹层、表单和滚动条。
