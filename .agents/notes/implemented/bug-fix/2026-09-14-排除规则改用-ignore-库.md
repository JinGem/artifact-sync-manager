# Agent Note: 排除规则改用 ignore 包

Status: implemented

## Problem

上传与下载界面声明使用 `.gitignore` 语法，原实现却通过自定义正则解释通配符。`doc/**/*` 无法匹配 `doc/` 下的直接文件，`!doc/test.txt` 的结果也因此与 Git 不一致。

## Decision

`src/main/fs/ignore.ts` 的 `compileRules()` 直接调用 `ignore().add(rulesText)`，`isIgnored()` 只统一 Windows 路径分隔符、删除根路径前导斜杠并按目录补充尾斜杠，匹配结果全部由 `ignore` 包决定。`src/main/fs/ignore.test.mjs` 覆盖递归通配、文件 negation、被忽略父目录阻断 negation、Windows 分隔符和 basename 规则。

## Alternatives considered

- **保留自定义正则解析器**：需要自行实现 `**`、negation、目录匹配和路径锚定，边界多且已有行为错误。
- **使用 `minimatch`**：擅长 glob 匹配，但不负责 `.gitignore` 的规则顺序、否定和父目录语义。
- **调用 Git 命令**：要求用户安装 Git，且对非 Git 工作目录和远程共享路径不适用。

## Consequences

排除规则与标准 `.gitignore` 行为一致，`ignore` 成为直接运行时依赖。测试通过 Node 内置测试运行器执行，不引入额外测试框架。
